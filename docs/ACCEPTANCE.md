# Codex Helper v1.1.0 需求与验收账本

## 目标结果

用户通过一个 Windows 桌面入口管理 Codex 官方账号和 API 连接，识别并保护个人 Skills、配置、会话和重要开发项目，能够创建加密增量快照、批量导出迁移包，并在主程序不可用时通过救援程序恢复。

## 不可妥协项

- 账号、API Key、项目秘密不以明文进入备份或日志。
- 账号/API 切换和 Codex 原位恢复前必须检查进程、文件锁并创建安全快照。
- 导入默认不激活账号、不启用陌生 Skill、不覆盖现有项目。
- 备份目标不能位于任一保护源内部；恢复路径不能越界。
- 长任务必须显示阶段、进度、取消、部分成功和可重试项。
- 所有分发产物文件名包含版本号。

## v1.1.0 默认交付范围

- WPF 桌面壳层、总览、连接、项目、快照、迁移、健康和设置入口。
- 自动识别 `CODEX_HOME`、关键 Codex 数据和 Git 项目。
- 官方账号档案的 DPAPI 加密保存、安全切换和旧版目录批量导入。
- 普通 API/Sub2API 档案模型、兼容性预检，以及配置/状态数据库/会话 JSONL 的事务切换。
- 内容寻址、去重、认证加密的本地增量快照。
- 批量 `.chbundle` 导出、导入预览、冲突处理和整批回滚；连接凭据使用包内第二层加密。
- 从旧版 Account Switcher/API Switcher 目录批量导入，默认不激活。
- 独立救援程序和版本化 Windows x64 自包含产物。
- GPT 主控、OpenCode Go 外部执行的双模型工作流；自动适配 Chat Completions 与 Anthropic Messages 模型协议，Key 仅保存于本机 DPAPI 保险库。

## 明确非目标

- V1.1.0 不做云端实时同步、S3/WebDAV、多设备同时写入同一仓库。
- 不自动轮换账号规避额度限制。
- 不替代 Git；双模型执行仅在用户主动启用的 Go 档案中按任务运行 Git 操作。
- 未经单独授权不发布 GitHub Release，不安装到系统目录。

## 性能预算

- 已缓存总览在 2 秒内可交互。
- 10 万文件扫描持续显示进度并可取消。
- 第二次备份只写入变化的数据块。
- UI 长任务不阻塞窗口消息循环，空闲内存目标低于 300 MB。

## 正常路径

1. 首次启动识别 Codex 根目录与常用项目。
2. 保存两个官方账号和一个 API 档案，安全往返切换。
3. 钉住项目并执行“立即保护”，生成可浏览快照。
4. 删除测试文件后恢复到新目录，内容哈希一致。
5. 批量导出账号、Skills 和设置，在干净数据目录中预览并导入。

## 高风险边界

- Codex 正在运行、SQLite/WAL 活跃、目标磁盘断开或空间不足。
- 中文、深路径、非法路径、重解析点、大文件和无权限文件。
- 错误迁移口令、损坏包、重复导入、同名不同身份档案。
- 备份或导入进程被强制结束后，旧快照和原数据保持完整。

## 真实交付环境

- 从版本化 EXE 启动，不依赖开发环境。
- 从现有 Account Switcher/API Switcher 目录迁移真实格式数据。
- 退出、重启和升级后设置、账号索引与备份仓库仍正确。
- Windows 10/11、100%/150%/200% DPI 与明暗主题可用。
