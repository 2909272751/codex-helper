# 安全与恢复说明

## 秘密如何保存

- 本机官方账号档案与 API Key 使用 Windows DPAPI（CurrentUser）保护。
- 快照仓库使用随机主密钥和 AES-256-GCM；主密钥只以 DPAPI 密文保存。
- 跨机器 `.chbundle` 使用 Argon2id 派生密钥并分块 AES-256-GCM 加密。
- 连接档案在迁移包内部再使用独立盐值和 AES-256-GCM 加密，临时 ZIP 不含明文凭据。
- API Key 不写入 `config.toml`，Codex 通过独立凭据助手按需读取。

## 安全默认值

- 导入连接档案不会自动激活，普通文件默认导入新目录且不覆盖同名文件。
- 符号链接/重解析点不会被跟随；导入和恢复路径必须位于目标根目录内。
- 账号/API 切换前要求 Codex 停止。配置、SQLite 和会话 JSONL 均先备份；失败后回滚。
- 日常项目扫描排除 `.git`、`bin`、`obj`、`node_modules` 等可重建目录，但保留 Git 未提交和未跟踪源文件。

## 恢复边界

- 本机快照仓库依赖创建它的 Windows 用户 DPAPI，复制到另一台机器后不能直接解锁。
- 跨机器、重装系统或更换 Windows 用户时，应提前创建 `.chbundle` 并妥善保存迁移口令。
- Rescue 程序默认恢复到新目录，不直接覆盖工作区。确认恢复内容后再由用户手动替换。
- 忘记迁移口令时无法绕过加密恢复；程序不会保存或上传口令。

## 建议

- 将快照仓库放在与项目不同的磁盘或受保护同步目录，但避免多台机器同时写同一仓库。
- 在重大升级、账号/API 切换和项目重构前创建快照。
- 对迁移包做第二份离线副本，并保存发布目录中的 SHA-256 校验文件。
